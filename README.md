The Food Rescue Platform is a web-based application aimed at reducing food wastage by connecting donors such as restaurants, events, and households with NGOs and individuals in need. The system enables users to post surplus food details, match with nearby receivers using location-based services, and manage requests efficiently through a secure authentication system. Built using modern web technologies like Node.js, Express, and a database system such as MongoDB/PostgreSQL, the platform ensures smooth data handling and real-time interaction. This project focuses on creating a meaningful social impact by minimizing food waste while helping provide meals to underprivileged communities.
